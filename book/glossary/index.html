This chapter is built for lookup, not for reading straight through. Every significant term and abbreviation used anywhere in the book appears below, alphabetized under letter headings, with a one-to-three-sentence plain-English definition and a link to the chapter where the idea is actually taught. Each entry is written to stand on its own: if you land here from a search, you should leave with a working definition, and the link tells you where the full story — the intuition, the math, the practice — lives.

Two conventions. First, abbreviations are alphabetized by how people actually say them: you will find BPE under B and sparse autoencoder (SAE) under S. Second, when a definition uses another glossary term, that term is usually bolded in its own entry somewhere below — this glossary is happy to be circular, because vocabulary always is. For mathematical symbols rather than words (∇\nabla∇, ⊙\odot⊙, E\mathbb{E}E, and friends), see the companion Notation Reference.

A

Ablation — An interpretability experiment that removes or neutralizes a component (a neuron, head, or direction) — typically by setting its activation to zero or to its mean — and measures how the model’s behavior changes. If behavior degrades, the component was doing something the task needed. → Causal Methods

Activation — The output value of a neuron or layer after its nonlinearity is applied; more loosely, any intermediate value flowing through a network during a forward pass. “Activation function” names the nonlinearity itself. → Activation Functions

Activation patching — A causal technique that runs a model on two inputs, then copies (“patches”) an internal activation from one run into the other to see which components carry the information that changes the output. Also called causal tracing or interchange intervention. → Causal Methods

Adam / AdamW (Adaptive Moment Estimation) — The default optimizer of deep learning: it keeps a running average of each parameter’s gradient (momentum) and of its squared gradient (a per-parameter scale), then takes steps normalized by that scale. AdamW is the variant that applies weight decay directly to the weights rather than mixing it into the gradient, and it is what nearly every large model since ~2019 trains with. → Optimizers

Agent — A language model wrapped in a loop: it observes a task, chooses an action (often a tool call), sees the result, and repeats until done. The model supplies judgment; the surrounding scaffold supplies memory, tools, and permission to act. → Agents, Tool Use, and MCP

AIME (American Invitational Mathematics Examination) — A hard high-school competition math exam repurposed as a benchmark for reasoning models; scoring well requires multi-step derivations, not recall. Widely cited in the o1/R1 era because scores moved dramatically with reasoning training. → Benchmarks and How to Read Them

ALiBi (Attention with Linear Biases) — A positional scheme that adds a penalty to each attention score proportional to how far apart the two tokens are, with a different slope per head. No position vectors at all; used by models like MPT and BLOOM before RoPE became dominant. → Positional Information and RoPE

Alignment — The broad project of making a model’s behavior match what its developers and users actually intend: helpful, honest, harmless, and steerable. In practice, the post-training pipeline (SFT, RLHF, and successors) plus the research on verifying it worked. → Post-Training I: SFT, Reward Models, RLHF

ANN (Approximate Nearest Neighbor) search — Finding vectors close to a query vector without comparing against every stored vector, trading a little recall for orders-of-magnitude speed. The engine inside every vector database; HNSW is the most common algorithm. → Retrieval-Augmented Generation

API (Application Programming Interface) — The contract through which software talks to other software; for LLMs, the hosted endpoint (send a prompt and parameters, receive tokens) through which closed models are used without access to their weights. → Open vs Closed Models

ARC-AGI (Abstraction and Reasoning Corpus) — François Chollet’s benchmark of small colored-grid puzzles designed so each task requires inferring a novel rule rather than applying memorized skills. Long resistant to LLMs; large test-time-compute systems made headline progress on it in 2024–2025. → Benchmarks and How to Read Them

Argmax — The index of the largest value in a list: arg max⁡izi\argmax_i z_iargmaxi​zi​ is which entry wins, not how big it is. Greedy decoding takes the argmax of the next-token probabilities. → Probability for Deep Learning

Attention — The mechanism at the heart of transformers: each position computes similarity scores against other positions, turns those scores into weights via softmax, and takes a weighted average of the other positions’ value vectors. In plain terms, each token asks “who is relevant to me?” and blends in what it finds. → Scaled Dot-Product Attention

Attention head — One independent copy of the attention mechanism, with its own query/key/value projections, running in parallel with the others in a layer. Different heads learn different relations (syntax, coreference, copying); interpretability studies heads individually. → Multi-Head Attention

Attention sink — The phenomenon where models dump large attention weight onto the first few tokens regardless of content, apparently using them as a “nowhere to look” default. Keeping these sink tokens resident is what makes streaming/window-limited inference work. → Long Context

Attribution graph — An interpretability artifact that traces, for one specific prompt, which features caused which other features and ultimately the output — a wiring diagram of the model’s computation on that input, built with transcoders. Introduced by Anthropic’s circuit-tracing work. → Circuits: Induction Heads to Attribution Graphs

Autoregressive — Generating a sequence one element at a time, with each new element conditioned on everything generated so far: P(x1,…,xn)=∏tP(xt∣x1,…,xt−1)P(x_1,\dots,x_n) = \prod_t P(x_t \mid x_1,\dots,x_{t-1})P(x1​,…,xn​)=∏t​P(xt​∣x1​,…,xt−1​). GPT-style language models are autoregressive; so is your phone’s keyboard predictor. → What a Language Model Is

AWQ (Activation-aware Weight Quantization) — A post-training quantization method that protects the small fraction of weights that matter most (identified by activation magnitudes) by scaling them before rounding everything to low precision. A standard way to serve models at 4-bit. → Inference: Sampling, Quantization, Serving

B

Backpropagation — The algorithm that computes the gradient of the loss with respect to every parameter in one backward sweep, by applying the chain rule from the output back through each layer and reusing intermediate results. It is what makes training networks with billions of parameters tractable. → Gradient Descent and Backpropagation

Base model — A model that has finished pretraining but received no post-training: a raw next-token predictor that continues text rather than answering questions. Chat assistants are base models plus SFT and preference tuning. → Post-Training I: SFT, Reward Models, RLHF

Batch / minibatch — The set of training examples processed together in one forward-backward pass, whose gradients are averaged before an update. “Batch size” is how many; large-model pretraining uses batches of millions of tokens. → Gradient Descent and Backpropagation

BatchNorm (Batch Normalization) — Normalizes each feature using the mean and variance computed across the batch, which stabilized deep vision networks from 2015 on. Rarely used in transformers, where LayerNorm/RMSNorm (statistics per example, not per batch) took over. → Normalization: BatchNorm to RMSNorm

Beam search — A decoding strategy that keeps the kkk highest-probability partial sequences at each step instead of committing to one. Standard in the machine-translation era; modern chat models mostly sample instead, because beam search favors bland, repetitive text. → Inference: Sampling, Quantization, Serving

Benchmark — A fixed dataset plus scoring rule used to compare models: MMLU for exam knowledge, SWE-bench for real software fixes, and so on. Useful but gameable — contamination, prompt sensitivity, and saturation all distort scores. → Benchmarks and How to Read Them

BERT (Bidirectional Encoder Representations from Transformers) — The 2018 encoder-only transformer trained with masked language modeling, which dominated NLP understanding tasks pre-GPT-3. Its descendants still power much of search ranking and embedding models. → Architecture Families: BERT to Decoder-Only

bf16 (bfloat16) — A 16-bit floating-point format that keeps fp32’s full exponent range but only 8 bits of precision, so it almost never overflows — which is why it replaced fp16 as the default training precision on modern accelerators. → Compute: GPUs, Precision, and Parallelism

Bias (parameter) — The constant added after a weighted sum, $y = w \cdot x

  • b$: it lets a neuron shift its threshold rather than always pivoting through zero. (Distinct from statistical or social bias, which is about systematic error in data or behavior.) → Neurons, Layers, and MLPs

Bits-per-byte (BPB) — A compression-flavored evaluation metric: the model’s average loss converted to bits and divided by the number of raw bytes of text, which makes models with different tokenizers comparable. Lower is better. → Evaluating Language Models

BLEU (Bilingual Evaluation Understudy) — The classic machine-translation metric: n-gram overlap between a generated translation and reference translations. It defined the seq2seq era’s progress and its limits — fluent paraphrases score poorly. → From seq2seq to Attention

BM25 — A decades-old keyword-based ranking function (a tuned refinement of TF-IDF) that scores documents by term overlap with the query. Still a strong retrieval baseline, and often combined with vector search in hybrid RAG. → Retrieval-Augmented Generation

BPE (Byte-Pair Encoding) — The dominant tokenization algorithm: start from bytes or characters, repeatedly merge the most frequent adjacent pair into a new token, stop at a target vocabulary size. GPT-family and most open models use byte-level BPE variants. → Tokenization

Bradley–Terry model — A statistical model of pairwise preferences: each option gets a scalar strength, and the probability that A beats B is the logistic sigmoid of the difference in strengths. It is the assumption underlying reward-model training and the DPO derivation. → Post-Training I: SFT, Reward Models, RLHF

C

Catastrophic forgetting — When fine-tuning on a narrow task overwrites capabilities the model had before. A core reason fine-tunes use small learning rates, few epochs, mixed-in general data, or parameter-efficient methods like LoRA. → Fine-Tuning You Can Actually Do

Causal mask — The triangular mask in decoder attention that blocks each position from attending to positions after it, enforcing that predictions depend only on the past. It is what makes parallel training of an autoregressive model possible. → Scaled Dot-Product Attention

CFG (Classifier-Free Guidance) — A diffusion-sampling trick: run the model both with and without the conditioning prompt, then push the output in the direction that separates them, scaled by a guidance weight. Higher guidance means stronger prompt adherence at some cost in diversity. → Diffusion and Image/Video Generation

Chain of thought (CoT) — Intermediate reasoning text a model produces before its answer, whether elicited by prompting (“think step by step”) or trained in as a reasoning model’s thinking phase. Whether the visible chain reflects the actual computation is the faithfulness question. → Chain-of-Thought Faithfulness

Chain rule — The calculus rule for differentiating compositions: ddxf(g(x))=f′(g(x)) g′(x)\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)dxd​f(g(x))=f′(g(x))g′(x). A neural network is a giant composition, so the chain rule — applied systematically — is backpropagation. → The Chain Rule, Jacobians, and Curvature

Chat template — The exact string format a chat model was trained to expect: special tokens delimiting system, user, and assistant turns. Using the wrong template silently degrades a model, which is a classic open-weights pitfall. → Post-Training I: SFT, Reward Models, RLHF

Chatbot Arena (LMArena) — A public evaluation where users chat with two anonymous models and vote for the better answer; votes are aggregated into Elo-style ratings. The most-watched holistic leaderboard, with known biases toward verbosity and formatting. → Benchmarks and How to Read Them

Checkpoint — A saved snapshot of a model’s weights (and often optimizer state) during or after training, used to resume after failures, roll back after loss spikes, or release the model. “A checkpoint” is often shorthand for “a trained model.” → The Training Run

Chinchilla — DeepMind’s 2022 result that models of the era were trained on far too little data for their size: for a fixed compute budget, loss is minimized near ~20 tokens per parameter. Modern models deliberately “overtrain” far beyond that because inference cost favors smaller models. → Scaling Laws

Chunking — Splitting documents into retrieval-sized pieces (by tokens, sentences, or structure) before embedding them for RAG. Chunk size and overlap are the unglamorous hyperparameters that most affect retrieval quality. → Retrieval-Augmented Generation

Circuit — A subgraph of a model’s components (heads, neurons, features) that together implement an identifiable algorithm, such as the induction-head copying circuit. Finding and verifying circuits is a central program of mechanistic interpretability. → Circuits: Induction Heads to Attribution Graphs

CLIP (Contrastive Language–Image Pretraining) — OpenAI’s 2021 model pair (image encoder + text encoder) trained so matching image–caption pairs land close together in a shared embedding space. It made zero-shot image classification work and became the standard vision front-end for early multimodal LLMs. → Multimodal Models

CNN (Convolutional Neural Network) — A network built from convolution layers that scan small learned filters across an image, sharing weights across positions. The architecture that launched deep learning’s vision era (AlexNet, ResNet) before transformers arrived. → CNNs and RNNs: The World Before Transformers

Common Crawl — The nonprofit web-scrape archive (petabytes of raw pages) that is the starting point of most open pretraining datasets, including C4, RefinedWeb, and FineWeb. Heavy filtering and deduplication turn it into usable training data. → Pretraining Data

Compute-optimal — Training the model size and data amount that minimize loss for a given compute budget (the Chinchilla condition). Contrast inference-optimal: smaller models trained on more data, cheaper to serve. → Scaling Laws

Constitutional AI — Anthropic’s method for reducing dependence on human preference labels: the model critiques and revises its own outputs against a written list of principles (the constitution), and those AI-generated preferences train the reward signal. The canonical form of RLAIF. → Post-Training I: SFT, Reward Models, RLHF

Contamination — Benchmark test data leaking into a model’s training set, so scores measure memorization rather than capability. A persistent, hard-to-rule-out confound in every public leaderboard. → Benchmarks and How to Read Them

Context parallelism — Splitting a single very long sequence across GPUs, so each device holds a slice of the tokens and attention is computed cooperatively (e.g., ring attention). What makes million-token training runs feasible. → Compute: GPUs, Precision, and Parallelism

Context window — The maximum number of tokens a model can attend over at once: prompt plus generation. Frontier windows grew from 2K (2020) to 128K–1M+ (2024–2026), with effective use often lagging nominal size. → Long Context

Continuous batching — A serving technique that admits and retires requests from a batch every decoding step, instead of waiting for the whole batch to finish. With PagedAttention, the reason modern inference servers achieve high GPU utilization. → Inference: Sampling, Quantization, Serving

Contrastive learning — Training embeddings by pulling matched pairs together and pushing mismatched pairs apart, usually with the InfoNCE loss. The recipe behind CLIP, sentence embedders, and most retrieval encoders. → Multimodal Models

Convolution — Sliding a small filter of learned weights across an input and taking a dot product at each position, producing a map of where the pattern occurs. Weight sharing across positions gives translation equivariance with few parameters. → CNNs and RNNs: The World Before Transformers

Cosine schedule — A learning-rate schedule that decays from the peak to near zero along a cosine curve after warmup. The pretraining default for years, now often replaced by WSD for flexibility in when to stop. → The Training Run

Cosine similarity — The cosine of the angle between two vectors: their dot product divided by the product of their lengths, ranging from −1-1−1 to 111. The standard measure of “how similar” two embeddings are, because it ignores magnitude. → Vectors and Spaces

Cross-attention — Attention where queries come from one sequence and keys/values from another — the decoder looking at the encoder in translation models, or a diffusion model’s image stream looking at the text prompt. Contrast self-attention, where all three come from the same sequence. → From seq2seq to Attention

Cross-entropy — The loss that scores a predicted probability distribution against the true outcome: −log⁡p(correct answer)-\log p(\text{correct answer})−logp(correct answer), averaged over examples. Minimizing it is equivalent to maximum-likelihood training, and it is the pretraining loss of every language model. → Loss Functions

Crosscoder — A sparse-autoencoder variant trained on activations from multiple layers or multiple models at once, so shared features get one dictionary entry. Used to track features across depth and to compare base vs fine-tuned models. → Sparse Autoencoders

Curse of dimensionality — The family of ways geometric intuition breaks in high dimensions: volume concentrates in shells, random vectors are nearly orthogonal, and data becomes sparse. Deep learning both suffers from it and — via the blessing of near-orthogonality — exploits it. → High-Dimensional Geometry

D

Data mixture — The recipe of a pretraining corpus: what fraction is web text, code, math, books, multilingual data, and synthetic data, plus how many times each is repeated. One of the most consequential and least published decisions in training a frontier model. → Pretraining Data

Data parallelism — Replicating the full model on every GPU, giving each a different slice of the batch, and averaging gradients across replicas each step. The simplest parallelism; ZeRO/FSDP shard its redundant copies. → Compute: GPUs, Precision, and Parallelism

DDIM (Denoising Diffusion Implicit Models) — A deterministic sampler for diffusion models that takes larger, non-Markovian steps, cutting generation from ~1000 steps to ~20–50 with little quality loss. The first big inference-speed win for diffusion. → Diffusion and Image/Video Generation

DDPM (Denoising Diffusion Probabilistic Models) — The 2020 formulation that made diffusion work: gradually add Gaussian noise to data over many steps, then train a network to reverse one step of noising at a time. The foundation of modern image and video generation. → Diffusion and Image/Video Generation

Dead neuron — A neuron whose activation is (near-)zero on nearly all inputs — a ReLU stuck in its flat region, or an SAE latent that never fires — contributing nothing and receiving no gradient. A training pathology to detect and revive. → Activation Functions

Decode (phase) — The second phase of LLM inference: generating tokens one at a time, each step reading the whole KV cache to produce one token. Memory-bandwidth-bound, unlike the compute-bound prefill. → Inference: Sampling, Quantization, Serving

Decoder-only — The architecture of every modern chat LLM: a single transformer stack with causal masking, trained purely on next-token prediction. It won over encoder–decoder designs by being simple, scalable, and equally good at understanding and generating. → Architecture Families: BERT to Decoder-Only

Deduplication — Removing repeated documents and near-duplicate passages (via hashing like MinHash, or embeddings) from pretraining data. Duplicates waste compute, amplify memorization, and inflate benchmark scores. → Pretraining Data

Dictionary learning — Decomposing signals as sparse combinations of entries from a learned overcomplete “dictionary” of basis directions. Sparse autoencoders are dictionary learning applied to a model’s activations, hoping the dictionary entries are the model’s features. → Sparse Autoencoders

Diffusion model — A generative model that learns to reverse a gradual noising process: start from pure noise and iteratively denoise into an image, audio clip, or video. The dominant paradigm for media generation (Stable Diffusion, Midjourney, Sora-class video models). → Diffusion and Image/Video Generation

Direction (feature direction) — A specific vector in activation space hypothesized to encode one concept, so that projecting an activation onto it measures “how much” of the concept is present. The linear representation hypothesis says most features are directions. → Features, Directions, and Probes

Distillation — Training a smaller “student” model to imitate a larger “teacher” — on the teacher’s output distributions or, for reasoning models, on its generated solutions. How R1-class reasoning behavior was compressed into small open models within weeks. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

DiT (Diffusion Transformer) — A diffusion model whose denoiser is a transformer over image patches instead of a U-Net. Scaled better and became the backbone of frontier image/video generators (SD3, Flux, Sora-class models). → Diffusion and Image/Video Generation

Dot product — The sum of elementwise products of two vectors, x⋅y=∑ixiyix \cdot y = \sum_i x_i y_ix⋅y=∑i​xi​yi​; geometrically, a measure of aligned length. It is the similarity operation inside attention scores, embeddings, and nearly everything else. → Vectors and Spaces

Double descent — The observation that test error can fall, rise near the point where a model just barely fits the data, then fall again as the model grows even larger. It complicates the classical bias–variance picture and partly explains why huge models generalize. → Regularization and Generalization

DPO (Direct Preference Optimization) — Preference tuning without a reward model or RL loop: a closed-form loss on (preferred, rejected) response pairs that provably optimizes the same objective as RLHF with a KL constraint. The workhorse of open-model post-training since 2023. → Post-Training II: DPO and Its Family

Dropout — Randomly zeroing a fraction of activations during training so the network cannot rely on any single unit, acting as a regularizer. Ubiquitous in the 2012–2019 era; largely dropped from LLM pretraining, where data scale regularizes instead. → Regularization and Generalization

E

Early stopping — Halting training when validation loss stops improving, before the model overfits the training set. The cheapest regularizer; standard in fine-tuning, mostly irrelevant in single-epoch pretraining. → Regularization and Generalization

Elo rating — A rating system from chess adapted to model leaderboards: pairwise wins and losses update scalar ratings so that rating gaps predict win probabilities. Chatbot Arena’s rankings are Elo-style (Bradley–Terry) fits to human votes. → Benchmarks and How to Read Them

Embedding — A learned dense vector representing a discrete thing — a token, sentence, image, or user — such that geometric closeness tracks semantic similarity. The embedding matrix of an LLM maps each vocabulary token to its vector. → Embeddings

Emergence — The claim that some capabilities appear abruptly at scale rather than improving smoothly. Contested: several celebrated cases are artifacts of all-or-nothing metrics over smoothly improving log-likelihood, but sharp transitions (in-context learning circuits) do exist. → Scaling Laws

Encoder–decoder — The two-stack transformer design (BART, T5, translation models): an encoder reads the input bidirectionally, a decoder generates output while cross-attending to it. Well suited to input→output tasks; lost to decoder-only for general-purpose LLMs. → Architecture Families: BERT to Decoder-Only

Entropy — The expected surprise of a distribution, H(p)=−∑ipilog⁡piH(p) = -\sum_i p_i \log p_iH(p)=−∑i​pi​logpi​: high when outcomes are unpredictable, zero when one outcome is certain. The floor beneath cross-entropy loss and the unit (“bits,” “nats”) of information theory. → Information Theory: Surprise, Entropy, and KL

EOS token (End-of-Sequence) — A special token whose generation means “I’m done”; its counterpart BOS marks a beginning. Chat models learn to emit EOS at the end of each turn — sampling settings that suppress it produce runaway generations. → Tokenization

Epoch — One full pass through a training dataset. Classic ML trained for many epochs; LLM pretraining typically sees most data about once, with only high-quality subsets repeated. → The Training Run

Expert — One of the parallel feed-forward networks in a mixture-of-experts layer, only a few of which run for any given token. Some architectures add a shared expert that every token uses. → Mixture-of-Experts

Expert parallelism — Placing different MoE experts on different GPUs and routing each token’s activations to the devices holding its assigned experts. The communication pattern (all-to-all) that makes MoE training an engineering problem. → Compute: GPUs, Precision, and Parallelism

Exploding gradients — When backpropagated gradients grow multiplicatively through depth or time until updates blow the model up, the mirror image of vanishing gradients. Mitigated by careful initialization, normalization, and gradient clipping. → Initialization and Gradient Pathologies

F

Feature — In interpretability, a property of the input that the model represents internally — “this is Python code,” “this sentence is in French,” “the Golden Gate Bridge” — ideally corresponding to a direction in activation space. What SAEs try to extract. → Features, Directions, and Probes

Few-shot prompting — Putting a handful of worked examples in the prompt so the model infers the task pattern via in-context learning, without any weight updates. GPT-3’s headline discovery. → What a Language Model Is

FFN (Feed-Forward Network) — The MLP sublayer in each transformer block: expand the hidden vector (typically ~4×), apply a nonlinearity, project back down. Roughly two-thirds of a dense model’s parameters live here, and evidence suggests much of its factual knowledge does too. → The Transformer, Piece by Piece

Fine-tuning — Continuing training of a pretrained model on a smaller, task- or style-specific dataset. Spans full-parameter training, parameter-efficient methods (LoRA), and the entire post-training pipeline. → Fine-Tuning You Can Actually Do

FlashAttention — An exact attention algorithm reorganized around GPU memory: it computes attention in tiles that fit in fast on-chip SRAM, never materializing the full attention matrix in slow memory. Made long contexts practical; standard everywhere since 2022. → The KV Cache and Efficient Attention

FLOPs (Floating-Point Operations) — The raw count of arithmetic operations, the standard currency of training compute. Rule of thumb: training takes about 6ND6ND6ND FLOPs for NNN parameters on DDD tokens; frontier runs sit around 102510^{25}1025–102610^{26}1026 FLOPs (fast-moving figure). → Compute: GPUs, Precision, and Parallelism

Flow matching — A generative framework that trains a network to predict the velocity field carrying noise to data along (nearly) straight paths, yielding simpler training and faster sampling than classic diffusion. Used by SD3 and Flux; the field’s current direction of travel. → Diffusion and Image/Video Generation

fp32 / fp16 / fp8 (floating-point formats) — Number formats trading precision for speed and memory: fp32 (32-bit) for master weights and sensitive accumulations, fp16/bf16 (16-bit) for most training math, fp8 (8-bit) for frontier-scale matmuls on recent GPUs (DeepSeek-V3 trained largely in fp8). See also bf16. → Compute: GPUs, Precision, and Parallelism

Frontier model — An informal term for the small set of most capable models at any moment (GPT-5-class, Claude, Gemini, and the strongest open models). The frontier moves every few months; the label is relative, not technical. → The Frontier Landscape

FSDP (Fully Sharded Data Parallel) — PyTorch’s built-in implementation of ZeRO-3-style sharding: parameters, gradients, and optimizer states are split across data-parallel GPUs and gathered only when needed. The default way to train large models without writing custom parallelism. → Compute: GPUs, Precision, and Parallelism

Function calling (tool calling) — An API pattern where the model is given JSON schemas of available tools and can emit a structured call instead of prose; the caller executes it and returns the result. The primitive underneath every agent. → Agents, Tool Use, and MCP

G

GELU (Gaussian Error Linear Unit) — A smooth activation, x⋅Φ(x)x \cdot \Phi(x)x⋅Φ(x) where Φ\PhiΦ is the Gaussian CDF: like ReLU but with a soft, curved transition near zero. The transformer default from BERT/GPT-2 until SwiGLU displaced it. → Activation Functions

Generalization — Performing well on data the model was never trained on — the actual goal of learning, as opposed to memorizing the training set. Why deep networks generalize as well as they do remains only partly understood. → Regularization and Generalization

GGUF — The file format of the llama.cpp ecosystem, packaging quantized weights plus tokenizer and metadata in one file for local inference on CPUs and consumer GPUs. The de facto standard for running open models on your own machine. → Inference: Sampling, Quantization, Serving

GPQA (Graduate-Level Google-Proof Q&A) — A benchmark of science questions written by PhD-holders to be unanswerable by searching — designed so domain experts far outscore skilled non-experts. A standard hard-knowledge test for frontier models. → Benchmarks and How to Read Them

GPT (Generative Pretrained Transformer) — Originally OpenAI’s name for its decoder-only models (GPT-2, GPT-3, GPT-4, GPT-5); now near-generic shorthand for the pretrain-then-finetune, next-token-prediction recipe itself. → Architecture Families: BERT to Decoder-Only

GPTQ — An early, influential post-training quantization method that rounds weights to low bit-width one column at a time while correcting for the error using second-order (Hessian) information. Made 4-bit LLMs credible. → Inference: Sampling, Quantization, Serving

GPU (Graphics Processing Unit) — The massively parallel processor that trains and serves nearly all deep learning, built around fast matrix multiplication and high-bandwidth memory (HBM). NVIDIA’s A100/H100/B200 line is the compute substrate of the LLM era. → Compute: GPUs, Precision, and Parallelism

GQA (Grouped-Query Attention) — Sharing each key/value head among a group of query heads (e.g., 32 query heads, 8 KV heads), shrinking the KV cache several-fold with minimal quality loss. The mainstream attention layout of 2023–2026 open models (Llama, Qwen, Mistral). → The KV Cache and Efficient Attention

Gradient — The vector of a function’s partial derivatives with respect to each input, pointing in the direction of steepest increase. Training follows the negative gradient of the loss with respect to the parameters. → Derivatives and Gradients

Gradient checkpointing (activation checkpointing) — Saving memory by discarding intermediate activations during the forward pass and recomputing them during the backward pass — spending ~30% more compute to fit much larger models or batches. → Compute: GPUs, Precision, and Parallelism

Gradient clipping — Rescaling the gradient whenever its overall norm exceeds a threshold (commonly 1.0), so a single pathological batch cannot launch the parameters into orbit. Cheap insurance against loss spikes; used in nearly every large run. → Initialization and Gradient Pathologies

Gradient descent — The core training loop: compute the loss’s gradient, step every parameter a small amount downhill, repeat. Every optimizer in this book is a refinement of this one idea. → Gradient Descent and Backpropagation

Greedy decoding — Always emitting the single most probable next token (temperature zero). Deterministic and fine for short factual answers; prone to repetition and blandness in long generations. → Inference: Sampling, Quantization, Serving

Grokking — The phenomenon where a network memorizes its training data early, then — long after training loss is at floor — abruptly transitions to genuine generalization. A favorite laboratory for studying what generalization is. → Regularization and Generalization

GRPO (Group Relative Policy Optimization) — DeepSeek’s simplification of PPO for reasoning training: sample a group of answers per prompt, score them, and use each answer’s advantage relative to the group mean — no learned value network needed. The algorithm behind R1 and much of the 2025 RLVR wave. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

H

Hallucination — A model producing fluent, confident, false content — invented citations, dates, APIs. Rooted in the fact that pretraining rewards plausible continuation, not truth; mitigated (not solved) by RAG, post-training, and verifier-checked reasoning. → Evaluating Language Models

Hessian — The matrix of a function’s second derivatives, describing local curvature: which directions are steep valleys versus flat plateaus. Too large to compute exactly for big networks, but approximations drive quantization (GPTQ) and optimizer design. → The Chain Rule, Jacobians, and Curvature

Hidden state — Any intermediate vector representation inside a network — in an RNN, the running summary passed between timesteps; in a transformer, each token’s vector at each layer (the residual stream). → CNNs and RNNs: The World Before Transformers

HNSW (Hierarchical Navigable Small World) — The dominant approximate nearest-neighbor index: a multi-layer graph where search starts on a sparse top layer and greedily descends toward the query’s neighborhood. What most vector databases run underneath. → Retrieval-Augmented Generation

HumanEval — OpenAI’s 2021 benchmark of small Python function-writing problems checked by unit tests; the original code benchmark, now saturated and succeeded by SWE-bench-style tasks. → Benchmarks and How to Read Them

Hyperparameter — A knob set by the experimenter rather than learned by training: learning rate, batch size, model width and depth, dropout rate. Tuning them well is a large share of practical deep learning. → The Training Run

I

In-context learning — A model’s ability to pick up a new task from examples or instructions in the prompt alone, with frozen weights. Emerged at GPT-3 scale and reshaped the field: prompting replaced fine-tuning for most uses. → What a Language Model Is

Induction head — An attention head implementing “find the last time this token appeared, and copy what came after it” — the first well-understood transformer circuit, and a key mechanism behind in-context learning. → Circuits: Induction Heads to Attribution Graphs

Inductive bias — The assumptions an architecture bakes in before seeing data: convolutions assume locality and translation invariance, RNNs assume sequential processing, transformers assume comparatively little — which is partly why they scale so well. → CNNs and RNNs: The World Before Transformers

Inference — Running a trained model to produce outputs, as opposed to training it. For LLMs, the prefill-then-decode loop, and an economics problem: across the industry, inference compute now rivals or exceeds training compute. → Inference: Sampling, Quantization, Serving

InfoNCE — The standard contrastive loss: for each matched pair, a cross-entropy that treats the true partner as the correct class among a batch of negatives. The training objective of CLIP and most embedding models. → Multimodal Models

Initialization (Xavier/He) — Schemes for choosing random starting weights whose variance is scaled to the layer’s size (fan-in/fan-out), so signals neither explode nor vanish through depth at the start of training. Bad initialization was a main reason pre-2010s deep nets failed. → Initialization and Gradient Pathologies

Instruction tuning — Supervised fine-tuning on (instruction, response) pairs so a base model learns to follow directions rather than merely continue text. The first stage of post-training; FLAN and InstructGPT made it standard. → Post-Training I: SFT, Reward Models, RLHF

IPO (Identity Preference Optimization) — A DPO variant that replaces the log-sigmoid loss with a squared-error objective, bounding the incentive and reducing DPO’s tendency to overfit preference pairs. → Post-Training II: DPO and Its Family

J

Jacobian — The matrix of all first partial derivatives of a vector-to-vector function: how each output coordinate responds to each input coordinate. Backpropagation is, mechanically, multiplying a chain of Jacobians. → The Chain Rule, Jacobians, and Curvature

Jailbreak — A prompt crafted to elicit responses the model’s safety training is meant to refuse — via role-play framing, encodings, many-shot examples, or optimization. The ongoing arms race that motivates interpretability-based safety checks. → Why Interpretability

K

KL divergence (Kullback–Leibler) — The measure of how a distribution qqq differs from a reference ppp: DKL(p∥q)=∑ipilog⁡(pi/qi)\KL(p \| q) = \sum_i p_i \log(p_i/q_i)DKL​(p∥q)=∑i​pi​log(pi​/qi​), zero only when they match. It appears as the RLHF penalty keeping the tuned model near its reference, in DPO’s derivation, and throughout information theory. → Information Theory: Surprise, Entropy, and KL

Knowledge cutoff — The date after which a model’s training data contains (approximately) nothing, so the model is oblivious to later events. RAG and search tools exist largely to compensate for it. → Retrieval-Augmented Generation

KTO (Kahneman–Tversky Optimization) — A preference method needing only unpaired thumbs-up/thumbs-down labels rather than chosen/rejected pairs, built on a loss-aversion-shaped value function from prospect theory. Useful when pairwise data is expensive. → Post-Training II: DPO and Its Family

KV cache — The stored key and value vectors of every processed token, kept so each new decoding step attends over the past without recomputing it. Its size — layers × tokens × KV heads × head dimension, times two for keys and values — is the central memory constraint of serving, driving GQA, MLA, and PagedAttention. → The KV Cache and Efficient Attention

L

Label smoothing — Softening one-hot training targets (e.g., 0.9 for the correct class, spreading 0.1 over the rest) so the model is penalized for extreme overconfidence. Common in classification and the original transformer; absent from LLM pretraining. → Loss Functions

Language model — A probability distribution over sequences of tokens: given context, it assigns a probability to every possible continuation. Everything a chat assistant does is sampling from a (heavily post-trained) language model. → What a Language Model Is

Latent diffusion — Running the diffusion process in the compressed latent space of a pretrained autoencoder (VAE) instead of raw pixel space, cutting compute enormously. The design behind Stable Diffusion. → Diffusion and Image/Video Generation

LayerNorm (Layer Normalization) — Normalizing each token’s hidden vector to zero mean and unit variance across its own dimensions, then rescaling with learned parameters. The transformer’s original stabilizer; RMSNorm is its lighter successor. → Normalization: BatchNorm to RMSNorm

Learning rate — The scalar multiplying each gradient step — the single most important hyperparameter. Too high diverges, too low wastes compute; hence warmup, schedules, and per-parameter adaptation (Adam). → Gradient Descent and Backpropagation

Linear representation hypothesis — The conjecture that models encode features as directions in activation space, with meaning composed by vector addition and read off by projection. Strong supporting evidence exists (probes, steering, SAEs), along with known exceptions (circular/nonlinear features). → Features, Directions, and Probes

LLM (Large Language Model) — A transformer language model with billions to trillions of parameters, pretrained on trillions of tokens, typically post-trained into an assistant. The central artifact this book explains. → What a Language Model Is

LLM-as-judge — Using a strong model to grade other models’ outputs — for benchmarks (MT-Bench, AlpacaEval), reward signals, or data filtering. Scales far beyond human graders, with known biases: position, verbosity, and self-preference. → Benchmarks and How to Read Them

Load balancing loss — An auxiliary MoE training term penalizing uneven token-to-expert routing, so no expert starves or becomes a bottleneck. Some recent designs (DeepSeek-V3) replace the loss with a bias-adjustment scheme instead. → Mixture-of-Experts

Logit — A raw, unnormalized score before softmax; an LLM’s final layer produces one logit per vocabulary token, and softmax turns them into next-token probabilities. Named for its role as the inverse of the logistic function. → What a Language Model Is

Logit lens — Reading a model’s mind mid-computation by applying the final unembedding matrix to intermediate residual-stream states, revealing what the model would predict at each layer. Crude but illuminating; refined by the tuned lens. → Causal Methods: Patching, Ablation, and Lenses

Logprob (log-probability) — The natural logarithm of a probability the model assigned, e.g., log⁡0.25≈−1.39\log 0.25 \approx -1.39log0.25≈−1.39. The working currency of evaluation and sampling APIs, because products of probabilities become sums of logprobs. → Probability for Deep Learning

LongRoPE — A long-context method that searches for per-frequency RoPE rescaling factors instead of using one formula, plus progressive extension — used to push models toward 2M-token windows. → Long Context

LoRA (Low-Rank Adaptation) — Fine-tuning by freezing the pretrained weights and learning small low-rank update matrices (W+BAW + BAW+BA with rank r≪dr \ll dr≪d), cutting trainable parameters by ~1000× with near-full-fine-tune quality. The default way individuals fine-tune open models. → Fine-Tuning You Can Actually Do

Loss function — The single number measuring how wrong the model currently is, which training minimizes; for LLMs, cross-entropy on next-token prediction. Choosing the loss is choosing what the model optimizes for. → Loss Functions

Loss spike — A sudden jump in training loss mid-run, caused by bad data batches, numerical instabilities, or optimizer state — the dread of every training team. Handled by clipping, skipping batches, and rolling back to checkpoints. → The Training Run

Lost in the middle — The finding that models retrieve information placed at the beginning or end of a long context far better than information buried in the middle. Improved in newer models, but still a reason prompt placement matters. → Long Context

LSTM (Long Short-Term Memory) — The gated RNN of the 2014–2017 era, whose learned input/forget/output gates protected information across long sequences well enough to power the first neural translation and assistant systems. The architecture transformers displaced. → CNNs and RNNs: The World Before Transformers

M

Mamba (selective state-space model) — The 2023 architecture that made SSMs competitive with transformers at moderate scale by letting the state update depend on the input (selectivity), with linear-time inference and no KV cache. Now common in hybrid designs interleaved with attention. → State-Space Models and Hybrids

Masked language modeling (MLM) — BERT’s pretraining objective: hide ~15% of tokens and train the model to reconstruct them from both directions of context. Great for understanding tasks; unsuited to generation, which is why GPT-style next-token prediction won. → Architecture Families: BERT to Decoder-Only

MCP (Model Context Protocol) — An open standard (from Anthropic, 2024) that lets any model connect to any tool or data source through a common client-server interface — “USB for AI tools” — replacing bespoke per-app integrations. → Agents, Tool Use, and MCP

Mechanistic interpretability — The research program of reverse-engineering what specific, causal computation a network’s weights implement — features, circuits, algorithms — rather than only observing input-output behavior. → Why Interpretability

MFU (Model FLOPs Utilization) — The fraction of a GPU cluster’s theoretical peak arithmetic that a training run actually spends on the model’s math. Frontier runs achieve roughly 30–55%; the rest is communication, memory, and bubbles (approximate, setup-dependent). → Compute: GPUs, Precision, and Parallelism

Min-p sampling — Truncated sampling with a relative threshold: keep only tokens whose probability is at least a set fraction (e.g., 5–10%) of the top token’s. Adapts to the model’s confidence better than fixed top-k/top-p; popular in open-model serving. → Inference: Sampling, Quantization, Serving

Mixed precision — Training with low-precision math (bf16/fp16, now fp8) for speed while keeping master weights and sensitive accumulations in fp32. Standard practice on all modern accelerators. → Compute: GPUs, Precision, and Parallelism

Mixture-of-Experts (MoE) — An architecture where each FFN layer holds many parallel experts and a router activates only a few per token, decoupling total parameters from per-token compute. How Mixtral, DeepSeek-V3, and most 2025–2026 frontier models get large cheaply. → Mixture-of-Experts

MLA (Multi-head Latent Attention) — DeepSeek’s attention variant that compresses keys and values into a small shared latent vector per token, caching only the latent — shrinking the KV cache by an order of magnitude while keeping per-head expressiveness. → The KV Cache and Efficient Attention

MLE (Maximum Likelihood Estimation) — Fitting parameters by maximizing the probability the model assigns to the observed data. Minimizing cross-entropy is exactly MLE — pretraining is maximum-likelihood estimation at civilizational scale. → Probability for Deep Learning

MLP (Multi-Layer Perceptron) — The basic neural network: alternating linear layers and elementwise nonlinearities. Universal in principle, and present inside every transformer block as the FFN sublayer. → Neurons, Layers, and MLPs

MMLU (Massive Multitask Language Understanding) — A 57-subject multiple-choice exam benchmark, the field’s headline knowledge score from 2021–2024, now largely saturated at the frontier (and partly contaminated); successors include MMLU-Pro and GPQA. → Benchmarks and How to Read Them

Model editing — Surgically modifying specific stored knowledge in a model’s weights — e.g., relocating “the Eiffel Tower is in Paris” — without retraining (ROME and successors). Works in demos; fragile at scale. → Steering and Model Editing

Momentum — An optimizer mechanism that accumulates an exponentially decaying average of past gradients and steps along it, smoothing noise and accelerating progress along consistent directions. A component of nearly every modern optimizer. → Optimizers

Monosemanticity — The property of a unit or feature responding to exactly one concept, as opposed to polysemantic neurons that fire for many unrelated things. The goal of sparse autoencoders is extracting monosemantic features from polysemantic activations. → Sparse Autoencoders

MQA (Multi-Query Attention) — The extreme of KV sharing: all query heads use one single key/value head, maximally shrinking the KV cache with some quality cost. GQA is the interpolation between MQA and full multi-head. → The KV Cache and Efficient Attention

MSE (Mean Squared Error) — The average of squared differences between predictions and targets, the standard loss for continuous regression and for autoencoder reconstruction (including SAEs). Corresponds to MLE under Gaussian noise. → Loss Functions

Multi-head attention — Running many attention heads in parallel on lower-dimensional projections and concatenating their outputs, letting the layer attend to several kinds of relationships at once. → Multi-Head Attention

Muon — A 2024–2025 optimizer that orthogonalizes each weight matrix’s momentum-averaged gradient (via Newton–Schulz iterations) before stepping, treating matrices as matrices rather than bags of scalars. Used in Moonshot’s Kimi K2 training at trillion-parameter scale. → Optimizers

N

Needle-in-a-haystack — A long-context stress test: hide one out-of-place fact (“the magic number is 42”) at varying depths in a long document and check whether the model can retrieve it. Necessary but far from sufficient evidence of long-context competence. → Long Context

Neuron — One unit of a network: a weighted sum of inputs plus bias, passed through a nonlinearity. In interpretability, “neuron” also names one coordinate of an activation vector — which, due to superposition, rarely means one thing. → Neurons, Layers, and MLPs

Next-token prediction — The pretraining task of every GPT-style model: given a token sequence, output a probability distribution over what comes next. Deceptively simple; doing it well across the internet’s text forces broad world modeling. → What a Language Model Is

NF4 (4-bit NormalFloat) — The quantization data type from QLoRA whose 16 levels are spaced to be equally probable under the roughly Gaussian distribution of trained weights, wringing more fidelity from 4 bits than uniform spacing. → Fine-Tuning You Can Actually Do

N-gram — A contiguous run of nnn tokens; n-gram language models predicted the next word from counts of the last n−1n-1n−1 words. The pre-neural baseline that neural LMs decisively beat — though n-gram statistics still explain a surprising share of LLM behavior. → What a Language Model Is

Norm (vector norm) — A vector’s length; the Euclidean (L2L_2L2​) norm is ∥x∥=∑ixi2\|x\| = \sqrt{\sum_i x_i^2}∥x∥=∑i​xi2​​. Norms appear in normalization layers, gradient clipping, weight decay, and cosine similarity’s denominator. → Vectors and Spaces

Normalization (layer) — Rescaling activations to a standard size at fixed points in the network so signal magnitudes stay controlled through depth — BatchNorm, LayerNorm, RMSNorm. One of the three pillars (with residuals and good init) that make very deep training stable. → Normalization: BatchNorm to RMSNorm

NTK-aware scaling — A context-extension trick that raises RoPE’s base frequency so high-frequency position dimensions are compressed less than low-frequency ones, extending usable context with little or no fine-tuning. A step on the road to YaRN. → Long Context

O

One-hot vector — A vector that is all zeros except a single 1 marking one category — the raw representation of a token before the embedding matrix maps it to a dense vector, and the target format of classification losses. → Embeddings

Open weights — A release model where the trained parameters are downloadable (Llama, DeepSeek, Qwen, Mistral), enabling local serving, fine-tuning, and interpretability — as distinct from open source (data and code too) and from closed API-only models. → Open vs Closed Models

Optimizer — The algorithm that converts gradients into parameter updates: SGD, momentum, Adam/AdamW, Muon. Its state (momentum and variance buffers) can consume more memory than the model itself. → Optimizers

ORPO (Odds Ratio Preference Optimization) — A reference-model-free method that folds preference optimization into the SFT loss via an odds-ratio penalty on rejected responses, collapsing two post-training stages into one. → Post-Training II: DPO and Its Family

Overfitting — Learning the training data’s noise and quirks instead of its generalizable structure: training loss keeps falling while validation loss rises. Its inverse, underfitting, is failing to fit even the training data. → Regularization and Generalization

P

PagedAttention — Managing the KV cache like virtual memory — in small non-contiguous pages allocated on demand — instead of reserving one giant contiguous block per request. Introduced by vLLM; roughly doubled serving throughput industry-wide. → Inference: Sampling, Quantization, Serving

Parameter — A number in the model that training adjusts — the entries of weight matrices and bias vectors. “A 70B model” means seventy billion of them. → Neurons, Layers, and MLPs

Pass@k — The probability that at least one of kkk sampled solutions is correct, the standard metric for code and math benchmarks. Comparing pass@1 against pass@100 measures how much capability sampling can unlock. → Benchmarks and How to Read Them

PEFT (Parameter-Efficient Fine-Tuning) — The family of methods that adapt a model while training only a small fraction of (usually added) parameters: LoRA, adapters, prompt tuning. What makes fine-tuning affordable outside labs. → Fine-Tuning You Can Actually Do

Perplexity — The exponential of average cross-entropy loss: intuitively, the effective number of choices the model is torn between per token (a model with perplexity 8 is as uncertain as a fair 8-sided die). Lower is better. → Evaluating Language Models

Pipeline parallelism — Splitting a model’s layers across GPUs so different devices handle different depth stages, with microbatches streaming through to keep everyone busy. The “bubble” of idle time at stage boundaries is its central inefficiency. → Compute: GPUs, Precision, and Parallelism

Polysemanticity — The observation that individual neurons typically respond to many unrelated concepts, which superposition predicts: models pack more features than dimensions, so features share neurons. The core obstacle to neuron-level interpretability. → Superposition and Polysemanticity

Position interpolation — Extending context by linearly rescaling token positions to fit inside the trained range (position 8000 becomes “4000” for a 4K-trained model), then briefly fine-tuning. The simplest RoPE-stretching method. → Long Context

Positional encoding — Any mechanism that tells attention where tokens are, since attention itself is order-blind: sinusoidal vectors, learned embeddings, ALiBi biases, or RoPE rotations. → Positional Information and RoPE

PPO (Proximal Policy Optimization) — The reinforcement-learning algorithm of classic RLHF: update the policy toward higher reward while clipping each update to stay close to the current behavior, with a learned value network estimating advantages. Effective but complex — hence DPO and GRPO. → Post-Training I: SFT, Reward Models, RLHF

Prefill — The first phase of inference: processing the entire prompt in parallel to populate the KV cache. Compute-bound and fast per token, unlike the bandwidth-bound decode phase; its length determines time-to-first-token. → Inference: Sampling, Quantization, Serving

Pre-norm (Pre-LN) — Placing the normalization layer before each attention and FFN sublayer rather than after (post-norm, the original design). Keeps a clean residual path through the whole network and trains stably without delicate warmup; the universal modern choice. → Normalization: BatchNorm to RMSNorm

Pretraining — The first, giant stage of training: next-token prediction over trillions of tokens of broad data, consuming most of the compute and producing a base model that post-training then shapes. → Pretraining Data

Probe (linear probe) — A small classifier — usually logistic regression — trained on a model’s frozen internal activations to test whether some information (part of speech, truthfulness, board state) is linearly readable there. Cheap evidence about representations, with correlational caveats. → Features, Directions, and Probes

Prompt — The input text (or token sequence) given to a model: user message, instructions, examples, retrieved documents. Prompt engineering is the craft of arranging it; the system prompt is its privileged first section. → What a Language Model Is

Q

QK and OV circuits — A decomposition of what an attention head does: the query-key (QK) circuit determines where it attends, while the output-value (OV) circuit determines what it moves from the attended position to the output. The vocabulary of transformer circuit analysis. → Circuits: Induction Heads to Attribution Graphs

QLoRA — LoRA on top of a 4-bit-quantized (NF4) frozen base model, with gradients flowing through dequantization into the low-rank adapters. Made fine-tuning 70B-class models possible on a single consumer or prosumer GPU. → Fine-Tuning You Can Actually Do

Quantization — Storing weights (and sometimes activations or the KV cache) in fewer bits — 8, 4, or fewer instead of 16 — trading a small accuracy loss for large memory and speed gains. The reason big models run on small hardware. → Inference: Sampling, Quantization, Serving

Query, key, value (Q, K, V) — The three learned projections of each token inside attention: the query is what a token is looking for, keys are what each token advertises for matching, and values are the content actually delivered when a match is made. → Scaled Dot-Product Attention

R

RAG (Retrieval-Augmented Generation) — Fetching relevant documents (via vector and/or keyword search) and placing them in the prompt so the model answers from provided evidence rather than parametric memory. The standard architecture for grounding models in private or current data. → Retrieval-Augmented Generation

ReAct (Reason + Act) — The agent pattern of interleaving reasoning text with tool actions and observations in one loop — think, act, observe, repeat. The conceptual ancestor of most modern agent scaffolds. → Agents, Tool Use, and MCP

Reasoning model — A model trained (via RLVR-style reinforcement learning) to produce a long private chain of thought before answering — o1/o3, R1, Claude’s extended thinking, Gemini’s thinking modes. Spends inference compute to buy accuracy on math, code, and hard reasoning. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

Regularization — Any technique that trades training fit for generalization: weight decay, dropout, early stopping, data augmentation, or the implicit regularization of SGD itself. → Regularization and Generalization

ReLU (Rectified Linear Unit) — The activation max⁡(0,x)\max(0, x)max(0,x): pass positives, zero out negatives. Its non-saturating positive half made deep networks trainable in 2012; successors (GELU, SiLU, SwiGLU) smooth its corner. → Activation Functions

Reranker — A second-stage retrieval model (usually a cross-encoder that reads query and document together) that re-scores the top candidates from fast first-stage search. Slower but much more accurate; standard in serious RAG stacks. → Retrieval-Augmented Generation

Residual connection — Adding a layer’s input directly to its output, y=x+f(x)y = x + f(x)y=x+f(x), so each layer learns an incremental update and gradients flow unimpeded through identity paths. The 2015 idea (ResNet) that made arbitrarily deep networks trainable. → Residual Connections and the Residual Stream

Residual stream — The interpretability view of a transformer: one running vector per token that every attention head and FFN reads from and additively writes to — a shared communication bus down the depth of the model. → Residual Connections and the Residual Stream

Reward hacking — A policy exploiting flaws in its reward signal instead of doing the intended task: flattering the reward model, gaming unit tests, producing confident-sounding filler. The reason RLHF constrains policies to stay near a reference and reward models get iterated. → Post-Training I: SFT, Reward Models, RLHF

Reward model — A network (usually a fine-tuned LLM with a scalar head) trained on human preference pairs to score how good a response is, standing in for human judgment inside the RLHF loop. → Post-Training I: SFT, Reward Models, RLHF

Ring attention — Computing exact attention over a sequence sharded across many devices by passing key/value blocks around a ring, overlapping communication with computation. The mechanism behind million-token context training. → Long Context

RLAIF (Reinforcement Learning from AI Feedback) — RLHF with the human preference labels replaced by a model’s judgments, usually guided by written principles (Constitutional AI). Scales preference data collection far beyond human labeling budgets. → Post-Training I: SFT, Reward Models, RLHF

RLHF (Reinforcement Learning from Human Feedback) — The post-training recipe behind ChatGPT: collect human preference comparisons, train a reward model on them, then optimize the policy (via PPO) to maximize reward while staying KL-close to the SFT model. → Post-Training I: SFT, Reward Models, RLHF

RLVR (Reinforcement Learning with Verifiable Rewards) — RL where the reward is computed by a checker, not learned from preferences: the math answer matches, the tests pass, the format validates. Unhackable-by-construction rewards made reasoning training work. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

RMSNorm (Root Mean Square Normalization) — LayerNorm minus the mean-subtraction and bias: rescale each vector by its root-mean-square, then multiply by a learned gain. Marginally cheaper, equally effective; the norm used by Llama, DeepSeek, and most modern LLMs. → Normalization: BatchNorm to RMSNorm

RNN (Recurrent Neural Network) — A network that processes sequences one step at a time, carrying a hidden state forward — the pre-transformer approach to language. Its sequential nature blocked parallel training, which attention removed; its spirit returns in state-space models. → CNNs and RNNs: The World Before Transformers

RoPE (Rotary Position Embedding) — Encoding position by rotating each query/key vector in a set of 2D planes by angles proportional to its position, so attention scores depend only on relative offsets. The dominant positional scheme in modern LLMs, and the thing long-context methods stretch. → Positional Information and RoPE

Router — The small learned gate in an MoE layer that scores every expert for each token and dispatches the token to the top-scoring few. Its balance and stability determine whether an MoE trains well. → Mixture-of-Experts

S

Sampling — Generating text by drawing each next token at random from the model’s (temperature-adjusted, usually truncated) probability distribution, rather than always taking the top choice. The knobs — temperature, top-k, top-p, min-p — trade diversity against reliability. → Inference: Sampling, Quantization, Serving

Scaling laws — The empirical finding that loss falls as a smooth power law in model size, data, and compute across many orders of magnitude — making frontier model performance roughly predictable and turning “train a bigger one” into a quantitative investment thesis. → Scaling Laws

Self-attention — Attention applied within one sequence: every token queries every (unmasked) other token of the same sequence. The transformer’s core operation; contrast cross-attention between two sequences. → Scaled Dot-Product Attention

Self-consistency — Sampling many chains of thought for the same problem and taking a majority vote over final answers. A simple, effective form of test-time compute for problems with checkable short answers. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

Self-supervised learning — Training on labels manufactured from the data itself — predict the next token, the masked word, the matching caption — so no human annotation limits scale. The insight that unlocked internet-scale pretraining. → What a Language Model Is

Seq2seq (sequence-to-sequence) — The 2014 encoder-decoder framework mapping an input sequence to an output sequence through a learned representation, originally with LSTMs for translation. Its fixed-vector bottleneck is what attention was invented to fix. → From seq2seq to Attention

SFT (Supervised Fine-Tuning) — Fine-tuning a base model on curated (prompt, ideal response) demonstrations with ordinary cross-entropy loss — the first stage of post-training, which teaches format and instruction-following before preference methods refine behavior. → Post-Training I: SFT, Reward Models, RLHF

SGD (Stochastic Gradient Descent) — Gradient descent using noisy gradient estimates from random minibatches instead of the full dataset. The “stochastic” noise is not merely tolerated — it appears to help generalization. → Optimizers

SigLIP — A CLIP successor that replaces the softmax contrastive loss (normalized across the whole batch) with independent per-pair sigmoid losses, training better at scale. The standard open vision encoder for VLMs in 2024–2026. → Multimodal Models

SiLU / Swish — The activation x⋅σ(x)x \cdot \sigma(x)x⋅σ(x) (input times its own sigmoid): smooth, non-monotonic near zero, slightly better than ReLU in practice. The nonlinearity inside SwiGLU. → Activation Functions

SimPO — A reference-free DPO alternative whose implicit reward is the length-normalized average log-probability of a response plus a target margin — simpler and competitive with DPO while resisting length gaming. → Post-Training II: DPO and Its Family

Sliding-window attention — Restricting each token to attend only to the last www tokens (e.g., 4096), bounding attention cost and cache size; deeper layers still integrate longer-range information indirectly. Often interleaved with full-attention layers in modern models. → The KV Cache and Efficient Attention

Softmax — The function that turns a vector of scores into a probability distribution: exponentiate each score and normalize by the sum. It converts logits into next-token probabilities and attention scores into attention weights. → Probability for Deep Learning

Sparse autoencoder (SAE) — A wide autoencoder trained to reconstruct a model’s activations as sparse combinations of learned dictionary directions, decomposing polysemantic activations into (often) interpretable monosemantic features. The workhorse tool of 2023–2026 interpretability. → Sparse Autoencoders

Speculative decoding — Accelerating inference by letting a small draft model propose several tokens that the large model verifies in one parallel pass, accepting the matching prefix. Exact same output distribution, typically 2–3× faster. → Inference: Sampling, Quantization, Serving

State-space model (SSM) — A sequence architecture that carries a fixed-size recurrent state evolved by (learned, structured) linear dynamics — linear-time in sequence length, constant memory at inference. Mamba is the breakthrough instance; hybrids with attention are the practical form. → State-Space Models and Hybrids

Steering vector — A direction added to a model’s residual-stream activations at inference to push behavior toward or away from a concept (refusal, sycophancy, a topic) without retraining. Both an interpretability probe and a control technique. → Steering and Model Editing

Superposition — The hypothesis (with strong toy-model and SAE evidence) that networks represent many more features than they have dimensions by assigning features to nearly-orthogonal, overlapping directions — exploiting sparsity and high-dimensional geometry. Explains polysemanticity. → Superposition and Polysemanticity

SWE-bench — A benchmark of real GitHub issues from real repositories: the model must produce a patch that passes the project’s held-out tests. The headline agentic-coding benchmark; “Verified” is the human-validated subset. → Benchmarks and How to Read Them

SwiGLU — The gated FFN nonlinearity used by nearly all modern LLMs: one linear projection is passed through SiLU and elementwise-multiplied with a second linear projection, letting the layer gate its own computation. → Activation Functions

Sycophancy — A post-trained model’s tendency to agree with the user, mirror their stated views, or validate their errors — a systematic bias traceable to human raters preferring agreeable answers. A live research and product problem. → Chain-of-Thought Faithfulness

Synthetic data — Training data generated by models rather than humans: rephrased web text, generated textbooks, model-written reasoning traces, self-play. A growing share of pretraining and the majority of some post-training corpora — with distribution-collapse risks if recycled carelessly. → Pretraining Data

System prompt — The privileged instruction block prepended (via the chat template) before user messages, setting the assistant’s identity, rules, and tools. Models are specifically trained to weight it above user instructions. → Post-Training I: SFT, Reward Models, RLHF

T

Teacher forcing — Training a sequence model by feeding it the true previous tokens at every step, regardless of what it would have generated — which makes training parallel, at the cost of a train/generate mismatch (exposure bias). → From seq2seq to Attention

Temperature — The divisor applied to logits before softmax at sampling time: below 1 sharpens the distribution toward the top choice, above 1 flattens it toward uniform. The main creativity/reliability dial in every model API. → Inference: Sampling, Quantization, Serving

Tensor — A multi-dimensional array of numbers — a 0-D tensor is a scalar, 1-D a vector, 2-D a matrix, and a batch of token embeddings is 3-D. The universal data structure of deep learning frameworks. → Matrices as Transformations

Tensor parallelism — Splitting individual weight matrices across GPUs so each computes a slice of every matmul, synchronizing within each layer. Bandwidth-hungry, so it usually stays within one node’s fast interconnect. → Compute: GPUs, Precision, and Parallelism

Test-time compute — Improving answers by spending more inference — longer chains of thought, many samples with voting or verification, search. The scaling axis that reasoning models industrialized: a second dial alongside train-time scale. → Reasoning Training: RLVR, GRPO, and the o1/R1 Era

Token — The atomic unit a language model reads and writes: a word piece, whole word, punctuation mark, or byte cluster from a fixed vocabulary. English averages roughly 3–4 characters per token in modern tokenizers. → Tokenization

Tokenizer — The fixed (not learned-with-the-model) component that converts text to token IDs and back, built by an algorithm like BPE over a training corpus. Its quirks explain a long tail of odd model behaviors, from arithmetic struggles to glitch tokens. → Tokenization

Tool use — A model acting through external functions — search, code execution, file editing, browsers — via function calling, extending it beyond text prediction into effecting change. The defining capability of agents. → Agents, Tool Use, and MCP

Top-k sampling — Truncating the next-token distribution to the kkk most probable tokens (renormalized) before sampling, cutting off the long tail of unlikely-but-possible junk. → Inference: Sampling, Quantization, Serving

Top-p (nucleus) sampling — Truncating to the smallest set of tokens whose cumulative probability exceeds ppp (e.g., 0.9), so the candidate pool adapts to the model’s confidence: narrow when certain, wide when not. → Inference: Sampling, Quantization, Serving

Transcoder — An interpretability module trained to imitate an MLP layer’s input→output function through a sparse feature bottleneck, making the layer’s computation decomposable. The building block of attribution graphs. → Sparse Autoencoders

Transformer — The 2017 architecture built from stacked blocks of multi-head attention and feed-forward sublayers on a residual stream, processing all positions in parallel. The substrate of nearly every frontier model. → The Transformer, Piece by Piece

Transformer block (layer) — One repeating unit of the stack: attention sublayer, FFN sublayer, each wrapped with normalization and a residual connection. Modern LLMs stack tens to ~100+ of them. → The Transformer, Piece by Piece

TTFT (Time To First Token) — The latency between sending a prompt and receiving the first output token, dominated by prefill; paired with inter-token latency (time between subsequent tokens) to characterize serving speed. → Inference: Sampling, Quantization, Serving

Tuned lens — A refinement of the logit lens that trains a small affine translator per layer to map intermediate states into the final layer’s representation space, giving much more reliable readouts of intermediate predictions. → Causal Methods: Patching, Ablation, and Lenses

U

Unembedding — The final linear map from the last-layer hidden state to vocabulary logits — the embedding operation in reverse, and sometimes literally the same matrix transposed (weight tying). → The Transformer, Piece by Piece

U-Net — The encoder-decoder convolutional architecture with skip connections between matching resolutions, borrowed from medical image segmentation to become the classic diffusion denoiser — now largely succeeded by DiTs at the frontier. → Diffusion and Image/Video Generation

Universal approximation theorem — The result that even a single-hidden-layer network with enough neurons can approximate any continuous function on a bounded region. Reassuring but weak: it says nothing about how many neurons, or whether gradient descent will find the approximation. → Neurons, Layers, and MLPs

V

VAE (Variational Autoencoder) — A generative autoencoder that encodes data into a smooth probabilistic latent space and decodes samples back. In modern image generation its main job is compression: latent diffusion runs inside a VAE’s latent space. → Diffusion and Image/Video Generation

Vanishing gradients — Gradients shrinking multiplicatively as they propagate backward through many layers or timesteps until early layers stop learning. The historic blocker for deep and recurrent networks, addressed by ReLU, careful initialization, normalization, and residual connections. → Initialization and Gradient Pathologies

Vector — An ordered list of numbers, viewed geometrically as a point or direction in space. The book’s foundational claim: meaning in neural networks lives in vectors, and similarity is geometry. → Vectors and Spaces

Vector database — A datastore built around approximate nearest-neighbor search over embeddings (with metadata filtering), serving the retrieval half of RAG. Examples: FAISS-based stores, pgvector, Qdrant, Pinecone. → Retrieval-Augmented Generation

Vision-language model (VLM) — An LLM that also accepts images (and often video): a vision encoder turns pixels into token-like embeddings that are projected into the language model’s input space. The standard multimodal recipe (LLaVA, GPT-4V-class, Claude, Gemini). → Multimodal Models

ViT (Vision Transformer) — A transformer applied to images by slicing them into fixed-size patches (e.g., 16×16 pixels), embedding each patch as a token, and attending over the patch sequence. Displaced CNNs at scale and supplies the vision encoders of VLMs. → Multimodal Models

vLLM — The open-source inference server that introduced PagedAttention and popularized continuous batching; alongside SGLang and TensorRT-LLM, the standard way open-weights models are served in production. → Inference: Sampling, Quantization, Serving

Vocabulary — The fixed set of tokens a model can read or emit, typically 32K–256K entries chosen when the tokenizer is trained. Vocabulary size trades sequence length against embedding-matrix size and per-step softmax cost. → Tokenization

W

Warmup — Ramping the learning rate from ~0 to its peak over the first fraction of training, giving optimizer statistics time to stabilize before full-size steps. A near-universal ingredient of transformer training. → The Training Run

Weight decay — Shrinking every weight slightly toward zero each step (equivalently, an L2L_2L2​ penalty), discouraging reliance on any single large weight. The “W” that AdamW gets right by decoupling it from the adaptive gradient scaling. → Optimizers

Weight tying — Using the same matrix for the input embedding and the output unembedding (transposed), saving parameters and coupling the two representations. Common in smaller models; large models typically untie. → Embeddings

Word2vec — The 2013 method that learned word embeddings from co-occurrence prediction and revealed vector arithmetic on meaning (king − man + woman ≈ queen). The proof of concept that geometry can encode semantics. → Embeddings

WSD (Warmup-Stable-Decay) schedule — A learning-rate schedule that holds the rate constant after warmup and applies the decay phase only at the end — so a run can be extended or stopped flexibly, with checkpoints “annealed” on demand. Increasingly the pretraining default. → The Training Run

Y

YaRN (Yet another RoPE extensioN) — A context-extension method combining per-frequency-band RoPE scaling (“NTK-by-parts”) with a mild attention temperature adjustment, extending context far beyond training length with brief fine-tuning. Used by DeepSeek, Qwen, and many others. → Long Context

Z

ZeRO (Zero Redundancy Optimizer) — DeepSpeed’s family of techniques that shard optimizer state (stage 1), gradients (stage 2), and parameters (stage 3) across data-parallel GPUs instead of replicating them, slashing per-device memory. FSDP is the same idea natively in PyTorch. → Compute: GPUs, Precision, and Parallelism

Zero-shot — Performing a task from instructions alone, with no examples in the prompt — as opposed to few-shot prompting. The default mode users experience; a capability that emerged with scale and instruction tuning. → Evaluating Language Models

z-loss — A small auxiliary loss penalizing the squared log of the softmax normalizer, (log⁡Z)2(\log Z)^2(logZ)2, keeping output logits from drifting to unstable magnitudes during large-scale training. Introduced for PaLM; common in MoE and frontier runs. → The Training Run
